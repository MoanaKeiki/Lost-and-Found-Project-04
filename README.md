# Lost & Found Website

1. Project Description

Lost & Found is a web-based platform that helps students report lost and found items, browse existing reports, and contact the owners of items.

The system allows users to:
- Register and log in using Supabase Authentication.
- Create lost and found item reports.
- Upload photos of reported items.
- Browse and filter listings.
- Open individual item details.
- Contact the person who created a report through Telegram, email, or phone.

2. Technologies Used

4. Database Structure

The project uses Supabase PostgreSQL.

Main tables:
- `items` — stores lost and found reports.
- `accounts` — stores additional user profile information.

Supabase Storage is used for listing images.

Supabase Authentication handles user registration and login.
